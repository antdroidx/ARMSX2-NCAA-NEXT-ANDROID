# ARMSX2 Extended icon

`savetowerforeground-purple.png` is a purple variant of the upstream launcher
artwork. Created with the built-in image generation tool using the pinned
upstream `savetowerforeground.png` as the edit target.

Prompt: Recolor the blue/cyan tower and glow to violet and purple with lavender
highlights and darker purple shaded faces; recolor the dark navy background to
violet-black. Preserve tower silhouette, geometric faces, square framing,
margins, gradients, glow softness and orbit trails. No added text or symbols.

The branding script installs the artwork and changes the adaptive background
to purple. It updates launcher labels to ARMSX2 Extended. Package identity and
signing remain unchanged, preserving updates to existing production installs.
