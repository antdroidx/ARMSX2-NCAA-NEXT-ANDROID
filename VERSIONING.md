# Release numbering

Release candidate 0.2.5-RC4 uses Android versionCode 128124, following test6
(128123) and published RC3 (128117). Package and production certificate remain
unchanged. Increase versionCode for each newly distributed APK.

The experimental_fastmem workflow input remains opt-in by default. Test5 and
test6 were built with it true. Public release selection is pending explicit
confirmation; saved/per-game Fastmem Off choices are respected when enabled.
